# Crisp

A macOS screen recorder built for quality: it records a maximum-fidelity master
(10-bit, high bitrate — gradients don't band) while logging every click and
cursor movement, then exports with Screen Studio-style animated zooms to where
you clicked.

## How it works

**Record phase** — ScreenCaptureKit captures the chosen source — a full
**display**, a single **window**, or a drag-selected **region** (⌘⇧4-style
overlay) — at native Retina pixel resolution, 60fps, with the cursor hidden.
Thumbnail previews of every source refresh every ~2 seconds in the picker. Frames go through
`AVAssetWriter` into `master.mov` using your chosen master codec:

- **HEVC 10-bit** (default) — Main10 profile at ~0.15 bits/pixel/frame
  (≈75 Mbps for 4K@60), far above typical screen-recorder bitrates.
- **ProRes 422 / ProRes 4444** — intra-frame masters; 4444 keeps full 4:4:4
  chroma (best possible gradient/color fidelity, biggest files ~1 GB/min).

Meanwhile a global mouse monitor logs clicks and samples the cursor position at
60Hz, timestamped on the same host clock as the video frames, into
`events.json` beside the master.

**Zoom editor** — opening a recording shows a preview with the zooms applied
live and a three-row timeline (video, zooms, framing). The camera follows the
cursor on its own; you set the zoom level and timing (drag a zoom's edges),
and can pin the viewport for part of a zoom when the action isn't under the
mouse. The **AI editor** hands the plan, the click log and annotated stills to
Claude Code or Codex for an editorial pass, with a before/after Compare.
Edits autosave to `plan.json` beside the master.

**Export phase** — "Export with zooms" clusters the clicks into zoom segments
(or uses the edited plan), bakes smoothstep-eased camera keyframes with the
cursor follower, and renders offline: the master is decoded at 10 bits, the
camera crop/scale is applied in Core Image (16-bit float working space), a
vector-drawn cursor and click ripples are composited on top, and the result is
written as high-bitrate 10-bit HEVC (`export.mov`).

The renderer runs on a fixed 60fps output clock, holding the last source frame
while the camera animates — necessary because ScreenCaptureKit only emits
frames when screen content changes.

Recordings live in `~/Movies/Crisp/<timestamp>/`.

**Screenshots** — the Screenshot button captures the currently selected
source (display/window/region) at 10 bits in Display P3 and saves a
**16-bit PNG** or **10-bit HEIC** (format via the button's dropdown) to
`~/Pictures/Crisp`. Native macOS screenshots are 8-bit, which is where
gradient banding comes from; these aren't. Crisp's own windows are excluded
from display/region shots.

## Installing

Grab `Crisp-<version>.zip` from [Releases](../../releases), unzip, and drop
`Crisp.app` in `/Applications`. The app is signed with a local certificate,
not notarized by Apple — on first launch, right-click → Open (or run
`xattr -dr com.apple.quarantine /Applications/Crisp.app`).

## Building & running

Two build variants, side-by-side installable, each with its own bundle id
(so each keeps its own Screen Recording grant):

```sh
./scripts/bundle.sh              # build/Crisp Dev.app (com.noey.crisp.dev) — hack on this
./scripts/bundle.sh --release    # build/Crisp.app     (com.noey.crisp)     — the official app
open "build/Crisp Dev.app"
```

## Releasing

```sh
# 1. bump VERSION in scripts/bundle.sh, commit
# 2.
./scripts/release.sh 0.2.0 "What changed…"
```

Builds the release app, zips it, tags `v0.2.0`, pushes, and publishes a
GitHub release with the zip attached. The app icon is generated by
`scripts/GenerateIcon.swift` (already committed as `assets/AppIcon.icns`).

First launch: grant **Screen Recording** permission when prompted
(System Settings → Privacy & Security → Screen & System Audio Recording),
then relaunch. Note: because the bundle is ad-hoc signed, macOS ties the
grant to the exact binary — after a rebuild you must re-toggle the
permission (or re-approve the prompt). A self-signed signing certificate
would make the grant persist; see Roadmap.

No other permissions are required — global *mouse* monitoring doesn't need
Input Monitoring (that's only for keystrokes, which Crisp doesn't capture).

While recording, Crisp hides itself; press **⌘R** (its global shortcut is
app-local, so bring Crisp forward first) or click Stop in the window.

## Pipeline self-test

```sh
swift build && .build/debug/Crisp --selftest
```

Synthesizes a gradient master with fake clicks and runs the full export
pipeline headlessly (no permissions needed). `CRISP_SELFTEST_KEEP=1` keeps the
output folder for inspection.
